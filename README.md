# 节奏教练 (RhythmCoach)

## 产品概述
**节奏教练**是一款面向中文口播、演讲排练、普通话训练、播客录制和会议汇报的 Android 工具。它以“**悬浮式节奏监控 + 半透明提词器**”为核心，在用户使用相机或其他应用时，实时显示讲话节奏，并按设定速度滚动中文稿件。

产品首要目标不是做高精度会议转写，而是帮助用户在口播时保持自然、稳定、可听懂的表达节奏，避免语速过快，并减少“低头读稿”的感觉。

## MVP 核心功能
* **悬浮节奏挂件**：跨 App 实时节奏展示，可拖动、折叠。
* **悬浮提词器**：半透明覆盖在任意 App 上方的提词器，支持自动匀速滚动及手动滚动。
* **语音停顿检测 (VAD)**：本地麦克风采集判断讲话/停顿状态，实现静音暂停滚动。
* **实时节奏分析**：通过纯本地算法估算 CPM (发声速率) 并绘制最近 30-60 秒节奏曲线。
* **复盘报告**：练习结束后提供发声时长、停顿次数、平均节奏等数据。
* **本地化与隐私**：所有语音分析和稿件管理均在本地完成，默认不上传数据。
