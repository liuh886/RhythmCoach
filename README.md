# RhythmCoach（节奏教练）

RhythmCoach 是演讲者、播客创作者的录制前排练工具。用提纲、提词、录音和可解释的节奏反馈，帮助你减少无效停顿与重复，控制节目时长，并让逐字稿听起来更像自然表达。

> 把表达练稳，再开始正式录制。

## 当前版本

**v1.0.1 · Stable**

- 极简首次引导，并可从顶部帮助按钮再次打开；帮助窗口会显示当前应用版本。
- 顶部提供深色与白色模式切换，选择会保存在当前浏览器，并在页面首次绘制前恢复。
- 支持安装为 PWA，在桌面或手机上以独立应用运行。
- 提供基于现有训练指标的轻量建议，每次只聚焦一个可执行改进点。
- 精选中文素材支持低干扰的重音、停顿和换气标注；英文界面提供独立的英文练习素材。
- 新增“平翘舌专项｜四十本杂志”，以故事和最小对立词训练平舌音与翘舌音。
- 核心训练数据保持本地优先，不引入语音内容识别或复杂云端服务。
- Cloudflare Web Analytics 负责汇总访问与 Web Vitals；GA4 `G-G4TTH49G1C` 补充有限产品采用事件，两者不接收稿件、录音或训练内容。

## 训练模式

- **定时提词**：按目标语速和稿件长度连续滚动，停顿不会暂停，适合 60 秒口播、演讲限时和录制排练。
- **语音跟随**：检测到讲话时滚动，持续静音后暂停，适合熟稿和节奏稳定训练。
- **播客训练**：以“开场—大纲—结尾”组织播客脚本，不自动滚动，由创作者手动下滑并把握内容进度；系统继续记录发声时长、长停顿和完成度。

为保持已有本地训练记录兼容，播客训练在内部仍沿用历史 `free` 模式标识；用户界面与文档统一显示为“播客训练”。

## 语言选择

RhythmCoach 首次打开时读取浏览器的首选语言列表：中文区域使用中文，其余语言默认使用英文。用户通过顶部按钮手动切换后，该选择保存在当前浏览器，并优先于后续的浏览器自动判断。

语言切换同时更新界面文案、精选素材、页面标题、描述和 `<html lang>`。用户自己保存的稿件和草稿属于内容数据，不会因为界面语言变化而被自动翻译或覆盖。

## 录音风格

- **自然**：保留自然动态，不增加自定义 EQ 或压缩。
- **播客**：使用温和高通、存在感增强和软拐点压缩，适合日常口播。
- **清晰**：提供更紧凑的动态和更明显的清晰度，并加入峰值保护。

发声、停顿和输入电平指标始终使用录音风格处理前的同一信号，因此切换风格不会改变训练测量口径。开始训练后，界面也会提示输入偏小、正常、过强或环境噪声较高。

完整参数、设计边界和参考资料见 [`docs/AUDIO_DSP.md`](docs/AUDIO_DSP.md)。

## 指标说明

RhythmCoach 不把用户设定的目标语速冒充为实测语速。当前版本的“整体估算语速”由已完成文本单位除以实际训练用时计算，因此包含自然停顿和呼吸，并与目标语速使用相同的时间口径。它适合训练反馈和前后比较，但仍不等同于逐字语音识别。

麦克风发声活动检测继续用于语音跟随、有效发声时长、发声占比、长停顿和输入提示；它不会再改变整体估算语速。训练记录同时保存实际用时、有效发声时长、发声占比、长停顿次数、完成度和整体估算语速。

旧版本保存的训练记录会在本地加载时，根据已保存的实际用时和完成字数自动重算语速，无需删除原有记录。

## PWA 安装

在支持 PWA 的浏览器中，顶部导航会出现安装入口。安装后，RhythmCoach 可作为独立应用打开，并在首次访问后提供基础离线使用能力。

## 本地运行

```bash
cd web
npm ci
npm test
npm run dev
```

生产构建：

```bash
npm run build
```

Cloudflare Web Analytics 的公开 site token 由生产构建环境提供：

```bash
VITE_CLOUDFLARE_WEB_ANALYTICS_TOKEN=<public site token>
```

GA4 使用固定公开 Measurement ID `G-G4TTH49G1C`，浏览器侧不需要任何 Google Analytics secret。

版本一致性检查：

```bash
npm run version:check
```

## 数据与隐私

稿件、训练记录和录音默认保存在当前浏览器本地。应用不主动上传麦克风音频。Cloudflare Web Analytics 用于汇总访问与 Web Vitals；GA4 当前仅记录打开排练应用和成功安装 PWA 等非敏感产品事件，不发送稿件、个人素材、录音、训练指标、邮箱或账户状态。清除浏览器站点数据会删除这些本地内容，重要录音请及时下载。

更完整说明见 [`PRIVACY.md`](PRIVACY.md)。

## 版本管理

RhythmCoach 从 `v1.0.0` 起采用语义化版本。`web/package.json` 是应用版本的唯一权威来源，帮助窗口直接读取该版本；Service Worker 缓存名、README、CHANGELOG 与隐私说明由自动脚本校验。详细规则见 [`docs/VERSIONING.md`](docs/VERSIONING.md)。

## 质量门禁

GitHub Actions 在 pull request 和 main 分支更新时执行版本一致性检查、`npm ci`、核心会话指标测试、训练建议测试、DSP 参数测试、时间标尺测试、主题切换测试、朗读标注测试、播客模板测试、语言解析测试、双语素材隔离测试以及 TypeScript/Vite 生产构建。面向浏览器的验收还覆盖首页 → 应用 → 启动排练的核心路径、移动端横向溢出，并保留桌面/移动端截图证据。

核心训练闭环和验收标准见 [`docs/CORE_TRAINING_LOOP.md`](docs/CORE_TRAINING_LOOP.md)。版本变化见 [`CHANGELOG.md`](CHANGELOG.md)。
