# RhythmCoach（节奏教练）

RhythmCoach 是一个本地优先、轻量小巧的 Web 口播训练工具。它把提词、发声活动检测、录音和训练复盘放在同一条流程中，帮助用户控制限时口播、减少长停顿，并比较同一稿件的多次练习。

> 把口播练稳，而不只是读完。

## 当前版本

**v1.0.0 · Stable**

- 极简首次引导，并可从顶部帮助按钮再次打开；帮助窗口会显示当前应用版本。
- 支持安装为 PWA，在桌面或手机上以独立应用运行。
- 提供基于现有训练指标的轻量建议，每次只聚焦一个可执行改进点。
- 核心训练数据保持本地优先，不引入语音内容识别、账户体系或复杂云端服务。
- 使用 Google Analytics 4 了解汇总访问情况和产品采用情况。

## 训练模式

- **定时提词**：按目标语速和稿件长度连续滚动，停顿不会暂停，适合 60 秒口播、演讲限时和录制排练。
- **语音跟随**：检测到讲话时滚动，持续静音后暂停，适合熟稿和节奏稳定训练。
- **自由演讲**：不自动滚动，由用户手动控制，系统记录发声时长、长停顿和文本进度。

## 录音风格

- **自然**：保留自然动态，不增加自定义 EQ 或压缩。
- **播客**：使用温和高通、存在感增强和软拐点压缩，适合日常口播。
- **清晰**：提供更紧凑的动态和更明显的清晰度，并加入峰值保护。

发声、停顿和输入电平指标始终使用录音风格处理前的同一信号，因此切换风格不会改变训练测量口径。开始训练后，界面也会提示输入偏小、正常、过强或环境噪声较高。

完整参数、设计边界和参考资料见 [`docs/AUDIO_DSP.md`](docs/AUDIO_DSP.md)。

## 指标说明

RhythmCoach 不把用户设定的目标语速冒充为实测语速。当前版本的“整体估算语速”由已完成文本单位除以实际训练用时计算，因此包含自然停顿和呼吸，并与目标语速使用相同的时间口径。它适合训练反馈和前后比较，但仍不等同于逐字语音识别。

麦克风发声活动检测继续用于语音跟随、有效发声时长、发声占比、长停顿和输入提示；它不会再改变整体估算语速。训练记录同时保存实际用时、有效发声时长、发声占比、长停顿次数、完成度和整体估算语速。

旧版本保存的训练记录会在本地加载时，根据已保存的实际用时和完成字数自动重算语速，无需删除原有记录。

## PWA 安装

在支持 PWA 的浏览器中，顶部导航会出现安装入口。安装后，RhythmCoach 可作为独立应用打开，并在首次访问后提供基础离线使用能力。

## 本地运行

```bash
cd web
npm ci
npm test
npm run dev
```

生产构建：

```bash
npm run build
```

版本一致性检查：

```bash
npm run version:check
```

## 技术栈

- React 19 + TypeScript
- Vite
- Web Audio API + MediaRecorder
- Zustand
- localforage / IndexedDB
- Framer Motion
- Google Analytics 4

## 数据与隐私

稿件、训练记录和录音默认保存在当前浏览器本地。应用不需要账户，也不主动上传麦克风音频。Google Analytics 仅用于访问与产品采用情况分析，不应接收稿件、录音或本地训练记录。清除浏览器站点数据会删除这些本地内容，重要录音请及时下载。

更完整说明见 [`PRIVACY.md`](PRIVACY.md)。

## 版本管理

RhythmCoach 从 `v1.0.0` 起采用语义化版本。`web/package.json` 是应用版本的唯一权威来源，帮助窗口直接读取该版本；Service Worker 缓存名、README、CHANGELOG 与隐私说明由自动脚本校验。详细规则见 [`docs/VERSIONING.md`](docs/VERSIONING.md)。

## 质量门禁

GitHub Actions 在 pull request 和 main 分支更新时执行版本一致性检查、`npm ci`、核心会话指标测试、训练建议测试、DSP 参数测试以及 TypeScript/Vite 生产构建。

核心训练闭环和验收标准见 [`docs/CORE_TRAINING_LOOP.md`](docs/CORE_TRAINING_LOOP.md)。版本变化见 [`CHANGELOG.md`](CHANGELOG.md)。
